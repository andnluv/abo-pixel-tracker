SillyTavern 기본 확장 API로 작동합니다. Tavern Helper가 필요하지 않습니다.

**베타 주의:** 실제 사용 중인 Vultr 서버 및 연결 프로필에서의 최종 동작 검증은 완료되지 않았습니다. 테스트 채팅 또는 백업본에서 먼저 실행하세요. 고급 세계관 규칙 중 일부는 아직 설계만 반영되어 있습니다.

4. 기존 파일을 GitHub 웹 UI에서 동일 이름으로 교체하기 어렵다면 GitHub Desktop의 파일 복사·커밋·Push 방식을 이용하거나, 저장소를 새롭게 재구성하세요. 중복 폴더를 생성하지 마세요.
5. SillyTavern 확장 관리 → 업데이트를 실행하고 브라우저를 새로고침합니다. 변경된 CSS가 그대로라면 강력 새로고침(Ctrl+Shift+R)을 해 보세요.
6. 창 상단에 **v0.3.8**가 표시되는지 확인하세요.

> 월드 인포 v3.4를 이미 가져왔다면 다시 가져올 필요가 없습니다. 새로 설치하는 경우에만 `worldinfo/ABO_Universal_WorldInfo_v3.4_EN.json`을 별도로 가져오세요.

## 초기 셋업

1. `▦ ABO` → 왼쪽 `SETUP`을 엽니다.
2. `CHAR + USER 분석 제안 만들기`를 클릭합니다. 현재 연결/선택한 저장 프로필의 분석 API가 **1회 호출**됩니다(비용 발생 가능).
3. 캐릭터 카드·페르소나로부터 성별, 제2성별, 신체 유형, 생식 능력, 생리·페로몬·언어·접촉 성향, 확정 취향 및 **잠재 취향 3~5개**와 별도의 확정 취향을 제안합니다. 분석 모델이 근거를 바탕으로 제안하고, 선택·해제는 사용자가 결정합니다.
4. `CARD FACT`는 카드·페르소나에 명시된 내용, `SUGGESTION`은 모델 추정입니다. 추론한 제안은 기본 미선택이므로 적용할 항목을 체크하고, 필요하면 값을 수정할 수 있습니다. 수동 변경으로 이미 고정된 항목은 자동 제안으로 덮어쓰지 않습니다.
5. `✓ 선택한 제안 적용`을 누르면 체크된 제안만 실제 채팅별 상태에 반영합니다. **분석 제안 생성만으로 상태가 바뀌지 않습니다.**
6. `제안 버리기`로 미적용 분석 초안을 폐기하거나 `다시 분석`을 누를 수 있습니다.

## 신체 유형 선택

| 캐릭터 | 선택 옵션 |
|---|---|
| 남성 Alpha | 기본 남성 생식기형 / 사용자 정의 |
| 여성 Alpha | 남성 복합형 / 여성 생식기형 / 사용자 정의 |
| 남성 Beta | 기본 남성 생식기형 / 사용자 정의 |
| 여성 Beta | 기본 여성 생식기형 / 사용자 정의 |
| 남성 Omega | 복합형 / 컨트보이형 / 남성 생식기형 / 사용자 정의 |
| 여성 Omega | 기본 여성 생식기형 / 사용자 정의 |

`사용자 정의`를 선택하면 특수 신체 구조 설명란이 나타납니다. 여성 Alpha는 별도 `가상 수태기관` 상세 입력란을 사용할 수 있으며, 여성 생식기형을 선택해도 수태·임신 능력이 유지됩니다.

## 디자인 설정

`▦ ABO` → `SETTINGS` → `색상 테마`:
- **시스템 설정에 맞춤** (기본값)
- **LIGHT**: 밝은 배경, 진한 글자와 선명한 테두리
- **DARK**: 이전보다 밝은 남청색 배경, 대비 높은 텍스트, 라벤더·민트 강조

창 우측 상단 **◐** 버튼으로 LIGHT/DARK를 빠르게 전환할 수 있습니다. 성별·ABO 드롭다운/레이블 글씨는 이전 대비 약 10~20% 이상 키웠고, Georgia 명조체 대신 Pretendard 우선의 산세리프를 사용합니다. Pretendard는 외부 CDN 연결 시 적용되고 차단 시 운영체제 글꼴로 대체됩니다. 글꼴 파일 자체는 포함하지 않습니다.

## 분석 모델 연결

`SETTINGS` → `분석에 사용할 API / 저장 연결 프로필`에서 선택합니다.
- **미설정**: 현재 SillyTavern 연결(기본)
- **저장된 연결 프로필**: SillyTavern Connection Manager의 프로필 선택
- **직접 API 연결**: OpenAI 호환 주소·모델명·세션 전용 키 입력

API 키는 채팅 메타데이터에 기록하지 않습니다. 수동 제안과 자동 RP 분석 모두 동일한 분석 연결 설정을 사용합니다.

## 테스트 및 한계

`npm run check && npm test`로 엔진과 프로필 제안 단위 테스트를 실행할 수 있습니다. 현재 분석 엔진은 모델이 추출한 사건에 따라 결과가 달라질 수 있으며, 모든 ABO 설정의 고급 처리를 완성한 정식 버전은 아닙니다.


## Persona sync fix (v0.3.1)
- Live active persona name, avatar identity, and description are resynced after chat/persona changes.
- CHAR and USER data continue to be stored per chat, but USER manual overrides and preference selections are kept separately per persona within a chat.
- Previous persona's pending setup proposals are discarded on identity change. In-flight model analysis for an old persona is rejected.
- Legacy USER-related events from another persona are not replayed into the newly selected persona; story time and CHAR-only events remain.
- SillyTavern controls which persona is actually selected. Use its persona locks if you want a different persona automatically selected per character.

### 페르소나 전환 문제 수정 (v0.3.1)

- 이전 버전은 채팅을 최초 연 시점의 USER 정보를 저장하고, 캐릭터나 페르소나가 변경되어도 다시 읽지 않았습니다.
- 이번 버전은 SillyTavern에서 **실제로 선택된 페르소나의 아바타 ID, 이름, 설명**을 다시 확인합니다. 캐릭터/채팅 변경 직후 페르소나 자동 선택이 늦게 완료되는 상황도 확인합니다.
- 같은 채팅에서 페르소나를 바꾸면 USER별 수동 설정과 취향을 분리해 보관하고, 다시 돌아오면 복원합니다. 이전 USER의 생리·수태 사건은 새 USER에게 적용되지 않습니다.
- 이미 존재하는 채팅 데이터는 삭제하지 않지만, 이전 버전에 저장된 프로필은 식별 정보가 충분하지 않아 최초 전환 시 자동 분리에 한계가 있을 수 있습니다. 중요한 채팅은 **설정 > 채팅 데이터 내보내기**로 먼저 백업하세요.
- **주의:** 이 확장이 SillyTavern의 페르소나 자체를 자동 변경하지는 않습니다. 캐릭터별로 다른 페르소나를 자동 선택하려면 SillyTavern 페르소나 관리 화면의 **캐릭터 연결(잠금)**을 설정해야 합니다. 확장은 ST에서 현재 선택된 페르소나를 그대로 반영합니다.

**GitHub 업데이트:** 저장소 최상위에 `index.js`, `persona-sync.mjs`(신규), `manifest.json`, `package.json` 등 ZIP 안의 파일을 업로드해 기존 파일을 교체하세요. 새 모듈이 없으면 확장이 로드되지 않습니다. SillyTavern의 확장 업데이트 후 페이지를 새로고침하고 화면 상단 버전이 `v0.3.1`인지 확인하세요.


## v0.3.3 저장된 연결 프로필 호출 수정

- 현재 연결은 성공하지만 동일한 연결을 저장 프로필로 선택하면 실패하는 경우를 개선했습니다.
- Connection Manager의 공식 `validateProfile`/`sendRequest`를 사용하여 Chat Completion과 Text Completion을 자동 구분합니다.
- 예전 코드의 `getContext().CONNECT_API_MAP` 의존과 별도 유형 판별을 제거했습니다.
- Text Completion에서 시스템/사용자 메시지를 공식 서비스가 Instruct 설정으로 변환하도록 수정했습니다.
- 프로필 요청에 강제 `temperature: 0.1`을 넣지 않아 모델 호환성을 높였습니다.
- 실패 시 가능한 한 실제 원인과 점검 방향을 표시합니다. 저장된 프로필은 자동으로 현재 연결로 대체하지 않습니다.

### 저장된 프로필이 여전히 연결되지 않으면

1. 추적기 **SETTINGS → 저장된 연결 프로필**을 선택하고 **분석 연결 테스트**를 눌러주세요.
2. 오류에 401, Unauthorized, API Key, Secret 등이 보이면 SillyTavern의 **연결 관리자(Connection Manager)**에서 해당 프로필을 **현재 API 연결로 활성화한 상태에서 Update**한 다음 재시도하세요. SillyTavern의 일부 버전에는 프로필 저장 당시 인증 정보가 다른 제공업체에 연결되는 문제가 보고되어 있습니다.
3. 그래도 실패하면 하단 상태 메시지와 브라우저 **F12 → Console → [ABO Pixel] connection test failed** 항목의 오류 문구를 알려주세요. **API 키·secret-id 값 자체는 공유하지 마세요.**
4. 본 배포 파일은 자동 모의 테스트를 통과했지만 실제 Vultr 서버 및 등록된 제공업체에 대해 원격 호출을 수행하지는 못했습니다.

## v0.3.6 — 발성·언어 성향 분석 및 헤더 디자인 보완

- 초기 프로필의 **발성 성향**은 평소 말투만 반복하지 않고, 인물의 서술 근거에 따라 친밀·NSFW 상황의 비언어적 음성 반응(호흡·신음·소리의 억제/표출·높낮이·음량 등)을 제안하도록 분석 지침을 명확히 했습니다. 명시되지 않은 내용은 `분석 제안`이며, 실제 사건으로 확정하지 않습니다.
- **언어 성향**은 호칭·존댓말·반말·도발·질문·요청과 친밀한 상황에서의 말투 변화를 별도로 분석합니다.
- 추가한 NSFW 어휘는 **참고용**입니다. 고정 번역이나 필수 취향 목록이 아니며, 기존 후보 수·확정 판정·선택 적용·내부 저장 ID는 변경하지 않았습니다.
- 제목 앞의 `✦ ▣` 기호를 폰트에 의존하지 않는 단일 CSS 픽셀 아이콘으로 교체했습니다. 라이트/다크 테마 모두 지원합니다.

## v0.3.5 — 초기 프로필 분석 결과 한국어 출력

- 초기 CHAR·USER 프로필 분석 모델에 **한국어 응답 규칙**을 추가했습니다. 페로몬·접촉·발성·언어 성향의 서술값, 제안 근거(reason), 취향 후보 표시명(label)을 자연스러운 한국어로 요청합니다. 모델이 규칙을 지키지 않는 경우는 있을 수 있으며, 응답을 재번역하는 별도 API는 호출하지 않습니다.
- 취향 후보는 **영문 snake_case 내부 ID + 모델이 생성한 한국어 표시명**을 함께 반환할 수 있습니다. `name_binding`처럼 미리 등록되지 않은 ID도 번역 사전으로 임의 번역하지 않습니다. 모델이 생성한 한국어 명칭을 화면에 보여주며, 선택 적용 이후에도 해당 표시명을 보존합니다. 취향 ID와 저장 엔진의 판정 방식은 변경하지 않았습니다.

## v0.3.8 — 초기 셋업 토큰 설정·JSON 재시도 보완

- 토큰 입력값이 12,000으로 되돌아가던 상한을 확장했습니다(512~65,536). 지원되는 최대 출력량은 모델과 API마다 다릅니다.
- `현재 연결 사용` 경로의 `generateRaw()`에도 `responseLength`를 명시적으로 전달하도록 수정했습니다. 저장 프로필과 직접 API 연결은 기존 방식으로 값을 전달합니다.
